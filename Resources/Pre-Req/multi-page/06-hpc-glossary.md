# 06. HPC Glossary

Below are some common terms you’ll hear throughout the bootcamp. You do not need to memorize these definitions. Think of this page as a quick reference whenever someone uses a term that sounds unfamiliar.



---

#### **Bash**

A popular shell used on Linux systems.

When someone says “open a Bash terminal,” they mean a terminal running the Bash shell.

------

#### **Cluster**

A collection of many computers connected together and working as a single system.

Most HPC resources are clusters.

Instead of running your code on one computer, you’re using hundreds or thousands.

------

#### **Command Line Interface (CLI)**

A text-based interface used to interact with a computer by typing commands.

Often used interchangeably with “terminal.”

------

#### **Commit**

A saved snapshot of your work in Git.

Think of it as a checkpoint you can return to later.

------

#### **Conda**

A tool used to install software and manage Python environments.

Conda helps prevent software conflicts between projects.

------

#### **Environment**

An isolated collection of software packages and settings.

Different projects can use different environments without interfering with each other.

------

#### **Git**

A version control system that tracks changes to files over time.

Git allows multiple people to collaborate safely on the same project.

------

#### **GitHub**

A website that hosts Git repositories and collaboration tools.

Many bootcamp projects use GitHub to share code and notebooks.

---

#### **Google Colab**

A browser-based environment for running Jupyter notebooks.

Google Colab allows users to write and execute Python code without installing software on their local computer.

------

#### **GPU**

Graphics Processing Unit.

Originally designed for graphics, GPUs are now widely used for machine learning and scientific computing because they can perform many calculations simultaneously.

------

#### **HPC**

High-Performance Computing.

Using powerful computing systems to solve problems that are too large or too time-consuming for a typical laptop.

------

#### **Jupyter Notebook**

An interactive document that combines code, text, images, and visualizations.

Many bootcamp projects use Jupyter notebooks as their primary interface.

------

#### **Kernel**

The process responsible for running code inside a Jupyter notebook.

If a notebook stops responding, restarting the kernel often fixes the problem.

------

#### **Linux**

An operating system commonly used in scientific computing and HPC environments.

Most HPC systems run Linux.

------

#### **Markdown**

A lightweight formatting language used to create formatted text using plain text syntax.

README files on GitHub are written in Markdown.

------

#### **Matplotlib**

A Python library used for creating graphs, charts, and other visualizations.

Many projects use Matplotlib to explore data and communicate results.

------

#### **Node**

An individual computer within an HPC cluster.

A cluster is made up of many nodes.

---

#### **NumPy**

A Python library used for fast numerical computing and working with arrays and matrices.

Many scientific computing, machine learning, and data analysis tools are built on top of NumPy.

------

#### **Pandas**

A Python library for working with tabular data.

Pandas makes it easy to load, organize, filter, and analyze data stored in spreadsheets, CSV files, and databases.

------

#### **Python**

A programming language commonly used for data science, machine learning, scientific computing, and HPC workflows.

------

#### **PyTorch**

An open-source machine learning framework used to build and train neural networks.

PyTorch is widely used in artificial intelligence, deep learning, and scientific research.

------

#### **Repository (Repo)**

A project folder managed by Git.

Repositories often contain code, notebooks, documentation, and datasets.

------

#### **Shell**

A program that interprets commands entered into a terminal.

Bash and Zsh are examples of shells.

------

#### **SSH**

Secure Shell.

A tool used to connect to remote computers from a terminal.

Many participants will use SSH to connect to HPC systems.

------

#### **TensorFlow**

An open-source machine learning framework developed by Google.

Like PyTorch, TensorFlow is used for building and training machine learning and deep learning models.

------

#### **Terminal**

The application used to interact with a shell.

On macOS, Terminal.app is one example.

Many people use the terms terminal and shell interchangeably.

------

#### **Zsh**

The default shell on modern versions of macOS.

Very similar to Bash and commonly used by developers and researchers.
