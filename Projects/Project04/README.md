# Gas cooling emulation project - Intro to HPC Bootcamp

Broad project goals:

- Gain beginner science background on star formation, gas cooling, and how astro simulations work
- Become familiar submitting scheduler jobs on an HPC cluster, and understand how to use nodes to your advantage with arrays and tasks
- Get comfortable navigating the terminal, using basic unix commands, and interfacing with GUIs
- Understand the benefits of notebooks, code scripting, and bash scripting
- Become AI model architects, understand the process of iterating on models and hyperparameters to increase efficacy
- Use data distribution techniques across GPUs and see how GPU scaling works, and what are some of the bottlenecks
- Use constrained prompt engineering when using AI models for understanding material and executing or writing code. If we have time at the end of the workshop, we will be vibe coding a simulation code that will use our trained surrogate to see it in action!
